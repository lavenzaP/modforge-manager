# Diagnostic Report

Use:

```text
More -> Export Diagnostic Report
```

The report is meant for troubleshooting. It includes:

- selected game profile summary
- enabled mod order
- mod status and file counts
- conflict and skipped-file summary
- latest apply verification result

Privacy defaults:

- Paths under your Windows user folder are written as `%USERPROFILE%`.
- Paths under the ModForge folder are written as `%MODFORGE%`.
- The report does not include file contents.

Review the JSON before sharing it publicly.
