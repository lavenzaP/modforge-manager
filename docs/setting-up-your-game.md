# Setting Up Your Game

Use the shortest path first:

1. Open ModForge Manager.
2. Click `More` -> `Add Steam Game`.
3. Pick the game if it appears.
4. Drag mods into the main window.
5. Press `Apply Changes`.

If your game is not listed, click `Choose Game Folder` and select the game
folder inside:

```text
Steam\steamapps\common
```

Examples:

```text
C:\Program Files (x86)\Steam\steamapps\common\Palworld
C:\Program Files (x86)\Steam\steamapps\common\StellarBlade
```

Profile actions under `More`:

- `Rename Game Profile` changes the profile name only.
- `Remove Game Profile` removes the profile from ModForge only.
- Game files and imported mod folders are not deleted by profile removal.
- `Change PAK Install Folder` is advanced. Use it only when a game needs a
  custom Unreal package folder.
