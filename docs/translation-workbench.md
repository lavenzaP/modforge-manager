# Translation Workbench

Translation support is intentionally limited in the first scaffold.

Initial target:

- Loose files and simple extracted workspace folders.
- JSON/CSV/TXT string discovery.
- CSV export for translation review.
- Validation for missing targets and placeholder drift.

Deferred:

- PO pipelines.
- Binary asset extraction.
- PCK/PAK repacking.
- Service-specific machine translation automation.
